隐私政策

最后更新：2026 年 9 月

一、我们访问哪些数据

AdPilot 通过各广告平台的官方 API（如 Google Ads API）读取用户明确授权的广告账户数据，包括：账户名称与账户 ID、广告计划与预算、消耗、展示、点击、转化等投放指标。

二、数据如何存储

所有数据仅保存在使用者本人的电脑本地（本地数据库文件）。登录凭证与客户端密钥均经过操作系统级加密后存储。

三、数据是否共享

不共享。AdPilot 没有服务器，不会将任何数据上传、传输或提供给任何第三方。软件仅在用户本机与各平台的官方 API 之间直接通信。

四、Google 用户数据的使用（Limited Use 声明）

AdPilot 对从 Google API 获取的信息的使用，将遵守 Google API 服务用户数据政策，包括 Limited Use 要求。Google 用户数据仅用于在用户本机展示其广告投放数据，不用于广告投放、不用于训练机器学习模型、不向第三方转让。

五、数据删除

用户可随时在软件内断开平台接入；删除本地数据库文件即可彻底清除全部数据。
