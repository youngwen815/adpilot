AdPilot
广告数据汇总桌面工具 · Windows 应用

AdPilot 是一款面向互联网广告优化师的 Windows 桌面应用，用于把分散在各个广告投放平台的数据汇总到一处，方便日常查看与管理。

主要功能

  • 通过各平台官方 API（Google Ads、TikTok、Meta 等）读取用户本人授权账户的广告数据
  • 按「项目」汇总展示各账户的预算、消耗、转化等投放指标与历史趋势
  • 全部数据仅保存在使用者本人的电脑上，用于个人工作查看与统计

关于数据

AdPilot 没有服务器，不会上传、不会共享任何用户数据；所有数据仅存储在使用者本人的电脑本地。
